A. WHAT THIS CLIP IS FOR
------------------------
The standalone text-layer tool: a PDF is opened in the browser and each page's digital text layer is read page by page. Pages with a text layer list their text; a scanned page has no text layer and is flagged with a solid red tag and a note that it should go to Image to Text. A summary strip shows the total characters and pages. Use it in a demo film or as an alternative frame set.


B. WHAT THE REAL PROCESS DOES (so the picture is truthful)
----------------------------------------------------------
The page uses pdf.js in the browser (nothing is uploaded): it renders a picture of every page and reads each page's text layer. In the TEXT panel every page gets a section: its page label (bold), its character count (grey), and a tag: grey "Native text" when the page has a text layer, solid red "No text layer" when it does not, followed by the page's text or, for a scanned page, a note "(no text layer: send this page to Image to Text)". A stats strip shows the file name, the total characters and the number of pages, with "Copy all" and "Download .md". No words or numbers are drawn in this video.
