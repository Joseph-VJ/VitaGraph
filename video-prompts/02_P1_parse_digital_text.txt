A. WHAT THIS CLIP IS FOR
------------------------
This clip is the first fifth of the Upload page's interactive stage. Its FIRST frame is the image every user sees when the Upload page opens, before the mouse moves, so frame 1 must be a calm, beautiful, finished still: a single report waiting to be read. Its LAST frame is handed to clip P2 as P2's first frame, so the last frame must be described and held exactly.

On the left of the stage the page shows the row "01  Parse digital text" with the real result (for example "5 pages, 4 with a text layer"). This clip shows that row's meaning without any words: a five-page report fans out, the text layer of each page is read by a red scan line, four pages light up as readable, and the fifth page is found to be a scan with no text layer and is flagged for OCR.


B. WHAT THE REAL PROCESS DOES (so the picture is truthful)
----------------------------------------------------------
VitaGraph opens the uploaded PDF with PyMuPDF and reads the digital text layer of every page, page by page. It counts the characters each page gives. A page that returns no usable text (a scanned image) is marked so that the next step (OCR) reads it. A progress of "characters known so far" grows as pages are read. In the reference demo the five pages give 1,284 / 1,102 / 968 / 1,347 / 0 characters of a 5,013-character report (the last 312 characters come later from OCR). The proportions below follow those numbers; no number is ever drawn.
