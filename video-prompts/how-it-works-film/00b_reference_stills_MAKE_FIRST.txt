REFERENCE STILLS ("ingredients"): make these FIRST with an image model (for example Gemini's image model), then attach them to the clips listed.
Google's own Veo 3.1 workflow does exactly this: character and setting images first, then each shot prompt "using the provided images".
Keep the files. Never regenerate them mid-project, because a new still means a new face.
Attach 3 reference images at most per clip (more images make the references fight each other).

- the face is sharp and symmetric, with nothing covering the eyes;
- there is no text anywhere in the image;
- the wardrobe matches the words above;
- in the hospital still, the red cross is a plain shape with no letters.
