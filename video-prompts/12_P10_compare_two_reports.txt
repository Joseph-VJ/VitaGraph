A. WHAT THIS CLIP IS FOR
------------------------
VitaGraph compares any two of the user's reports side by side. This clip builds the Compare page exactly as it works: three report-pair buttons appear, the chosen pair turns red, the comparison table writes itself row by row, the baseline and follow-up values fill their columns, the change is computed (follow-up minus baseline), and each row receives its status tag: pale red "Higher" for values that rose, grey "One report" where only one of the two reports has the value. Use it in a demo film or as an alternative frame set.


B. WHAT THE REAL PROCESS DOES (so the picture is truthful)
----------------------------------------------------------
For 2 to 4 reports the page offers buttons for consecutive pairs plus first-to-last (for 5 or more reports, two selects). For the chosen pair it loads each report's measurements, matches tests by name, and fills a table: biomarker (bold) with its unit (grey), baseline value, follow-up value, change = follow-up minus baseline (bold), status tag: Higher / Lower / Unchanged / One report. Values that exist in only one report show a dash. In the reference demo: Hemoglobin 13.1 -> 14.0 (+0.9, Higher), Vitamin D 18 -> 32.0 (+14, Higher), and four tests present only in the latest report (One report). No word or number is drawn in this video.
