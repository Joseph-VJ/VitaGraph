A. WHAT THIS CLIP IS FOR
------------------------
The sixth backend stage after indexing ("graphed"): VitaGraph turns the report into a knowledge graph. This clip shows the graph exactly as the Knowledge Graph page draws it: a hand-drawn software-3D node cloud above a perspective floor grid, nodes appearing type by type (subject, reports, sections, biomarkers, values, uncertainty), slow rotation, then one subgraph (a biomarker's trend across three reports) lighting up red with the app's own expanding focus rings. Use it in a demo film or as an alternative frame set.


B. WHAT THE REAL PROCESS DOES (so the picture is truthful)
----------------------------------------------------------
The graph builder (NetworkX) links: the person (subject) to each report; each report to the sections it contains; each section to its biomarkers; each biomarker to its measured values; each value to the report and date it came from; uncertain extractions become "uncertainty" nodes and are always labelled uncertain. The app draws it on a 2D canvas that fakes 3D (yaw rotation, pitch 0.4 rad, perspective focal length 3.4, painter's order far to near, nearer nodes darker and larger). Node shapes by type: subject = filled square, report = ring, section = diamond, biomarker = filled circle, value = small grey dot, uncertainty = dashed red ring. Auto-rotation is 0.192 rad per second. The build reveals one type every 0.34 s, each node growing over 0.42 s with an ease-out cubic. A focus fades other nodes to 40% and other edges to 7%, turns the focus nodes and their edges red, and sends one ring from each focus node that expands and fades over 1.2 s. No labels are drawn in this video (labels are text).
